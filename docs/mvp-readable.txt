Codex Build Goal: SaleScout Phase 1 MVP
You are building Phase 1 of SaleScout, a mobile-first, AI-powered garage sale discovery app.
SaleScout helps users discover nearby garage sales through a crowdsourced map. Instead of requiring
every sale owner to manually create a listing, users can quickly report garage sales they find by taking a
photo. The app uses location, photo upload, timestamp, and AI-generated metadata to create temporary
garage sale listings that other users can verify through check-ins.
The core product loop is:
Snap
->
Auto-List
->
Discover
->
Check In
->
Verify
->
Expire
The Phase 1 goal is to build a working MVP where users can:
Sign up and log in.
View nearby garage sales on a map.
Create a crowdsourced garage sale listing by taking/uploading a photo.
Automatically attach the user's current GPS location to the listing.
Add optional title, description, categories, and comments.
See active listings near them.
Tap a listing to view details.
Check in at a sale.
Report whether the sale is still open, closed, worth the stop, picked over, or category-specific.
Add comments to a listing.
Save favorite listings.
Automatically expire listings after 48 hours of inactivity.
Allow listings to close sooner if enough users report that the sale is closed.

Listing Expiration Logic
Listings should expire automatically.
Rules:
A listing expires 48 hours after created_at by default.
A listing also expires if it has not received a "Still Open" verification in the past 24 hours.
A listing closes early if 2 or more unique users mark it as Closed.
Expired or closed listings should not appear on the main map.
Expired listings may remain in the database for history and analytics.
Create a scheduled job or backend function to mark stale listings inactive.

MVP User Stories
User Story 1
As a user, I want to open the app and see nearby active garage sales on a map so I can quickly decide where
to go.
User Story 2
As a user, I want to take a photo of a garage sale sign or driveway sale so the app can quickly create a listing
for other users.
User Story 3
As a user, I want to check in and report whether a sale is still open so others do not waste time.
User Story 4
As a user, I want to comment on a sale so others know what kind of items are available.
User Story 5
As a user, I want old sales to disappear automatically so the map stays accurate.
Important Product Principle
Phase 1 should prioritize speed and usefulness over perfection.
The app should make it extremely easy for users to contribute a sale in under 15 seconds.
The fastest contribution flow is more important than seller-side listing customization.
